# GeodomDesk

基于 RustDesk 的独立远程工具，支持 Windows x64、Ubuntu amd64 和 Android ARM64，可与官方客户端共存。

## 主要特性

- **固定连接**：客户端使用编译时配置的服务器地址、公钥和 API。
- **独立运行**：应用名称、图标、服务、安装目录、配置、IPC 和辅助进程独立。
- **协议兼容**：沿用官方设备 ID、加密、打洞、中继及 WebSocket 实现。
- **登录引导**：服务端要求账号登录时打开登录窗口，停止无效重试。
- **克隆修复**：Ubuntu 配置记录独立硬件绑定，保留手动修改 ID 的能力，仅在检测到硬件变化时修复副本 ID。
- **资料迁移**：新安装首次启动自动导入；设置中仍可手动导入。两者只接受 ID 服务器公钥匹配的设备资料，保留独立设置。
- **ID 恢复**：在“更改 ID”旁恢复自动分配的默认 ID，服务端确认可用后切换，保留密码和个人设置。
- **上游同步**：定时拉取 RustDesk 官方稳定版，自动验证、合并定制并发布。
- **版本一致**：显示版本跟随官方，内部构建序号支持同版本修复更新。
- **可信更新**：独立更新通道，保留 Ed25519 签名、SHA-256 和下载大小校验。

## 构建与发布

**Sync RustDesk Upstream** 每 12 小时检查官方稳定版。新版本通过 Windows 和 Ubuntu 原生检查后自动合并。**Build GeodomDesk** 从合并后的提交构建 Windows、Ubuntu 和 Android。

三种平台通过构建和产物校验后发布 Release。云端核对原生安装文件的来源和摘要，生成签名更新清单，再切换下载和更新指针。
