# GeodomDesk

基于 RustDesk 的独立远程工具，支持 Windows x64 和 Ubuntu amd64，可与官方客户端共存。

## 主要特性

- **独立运行**：应用名称、图标、服务、安装目录、配置、IPC 和辅助进程独立。
- **协议兼容**：沿用官方设备 ID、加密、打洞、中继及 WebSocket 实现。
- **登录引导**：服务端要求账号登录时打开登录窗口，停止无效重试。
- **可选迁移**：在设置中导入官方客户端的设备记录、收藏与备注，保留独立设置。
- **持续同步**：定期检查官方稳定版，合并定制后重新构建。
- **版本一致**：显示版本跟随官方，内部构建序号支持同版本修复更新。
- **可信更新**：独立更新通道，保留 Ed25519 签名、SHA-256 和下载大小校验。

## 构建与发布

GitHub Actions 原生构建 Windows、Ubuntu，不使用 Docker。每 6 小时检查官方稳定版，也可手动运行 **Build GeodomDesk**。官方源码与实际定制均未变化时跳过，纯说明修改不重编译。

两种平台均构建成功后才发布 Release；发生合并冲突、构建或校验失败时，保留当前版本。云端发布程序根据 Release 制作安装包和更新清单。

完整二进制的共存安装及互通仍需构建后实机验证。

## 开发与维护

客户端扩展、身份隔离、登录处理、更新通道和上游合并分别维护，避免把定制散落在临时源码中。
