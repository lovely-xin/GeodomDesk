# 实测和清理验证

设备由用户指定时核对该设备。通用能力验收优先从最近访问中挑选与平台和授权匹配的在线设备。用只读命令或应用握手确认真实结果。

| 场景 | 通过条件 |
| --- | --- |
| Linux 或 Windows 经 TCP 执行 | 选用发起端支持的 TCP 隧道方式，确认目标身份、实际命令通道、退出码和输出。 |
| Windows 终端回落 | 记录 TCP 隧道无法建立的证据，确认终端独立获准，核对 PowerShell 的真实输出。 |
| 中转与显式映射 | 核对 A 的身份、B 的身份及实际服务握手，关闭后确认 UUID 消失、端口释放。 |
| 常驻会话 | 核对复用与重新建连，验证断开连接和退出进程的区别。 |
| 独立 CLI 注销 | 用无桌面登录且无单次账号覆盖的隔离配置测试。登录后用只读 `probe` 验证设备，注销后在相同隔离环境发起新探测，确认停在账号认证阶段。支持 `account status` 时可辅助核对来源。仍有桌面会话的环境可能继续使用桌面登录。 |

记录版本、CLI 类型、目标平台、实际通道和清理结果。仅在 CLI 无法完成且用户明确授权时使用电脑操作验证界面。
